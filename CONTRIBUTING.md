# Contributing

Thank you for helping. Snaglist stays one file with no libraries, so it is easy to add and easy to remove.

- Try changes on the demo page: run `python3 -m http.server 8777 --bind 127.0.0.1` here and open
  http://127.0.0.1:8777/.
- Check the whole journey with the keyboard only, in light and dark, on a phone width and at 200% text.
- Never add anything that collects personal information, and update `docs/PRIVACY.md` with anything new that
  a report holds.
- Words follow the [content design guide](https://github.com/TheMightyTRex/design-system/blob/main/docs/CONTENT-DESIGN.md):
  British English, sentence case, no em dashes, no contractions.
- Run `tools/install-hooks.sh` once, so the privacy check runs before each commit.
