# Security

Please report security and privacy problems privately, through GitHub's **Report a vulnerability** button on the
**Security** tab of this repository, not in a public issue. Say what you found, how to reproduce it and which
version of Snaglist you use.

Only the newest release gets fixes. To update, copy the newest `snaglist.js` over your old one.

How Snaglist protects people, what the November 2026 security check found and fixed, and which tests pass:
[docs/SECURITY-AND-TESTS.md](docs/SECURITY-AND-TESTS.md).
