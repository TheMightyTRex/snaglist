# Report an issue on a page

Tell the site's team about something on a page that is wrong, confusing or hard to use. You choose the part of
the page, say what is wrong, and check the report before it goes.

## Before you begin

- The site must have Snaglist turned on. You will find a **Report an issue** button on each page. If there is
  none, read [If Report an issue does not appear](if-report-an-issue-does-not-appear.md).

## Steps

1. Go to the page with the problem.
2. Select **Report an issue**. A bar appears with the words "Choose the part with the issue".
3. Choose the part with the problem:
   - With a mouse or touch screen, move over the page and select the part. A box shows what will be chosen.
   - With a keyboard, press Tab until the part is outlined, then press Enter.
   - For a problem with the page as a whole, select **Whole page**.
   - To stop without reporting, select **Stop** or press Escape.
4. The **Report an issue** form opens. Under **Where**, check it names the part you meant. If not, select
   **Choose again**.
5. Under **What kind of report**, choose the one that fits best, such as **Something is broken**, **Looks
   wrong** or **Slow**. The questions below change to suit it.
6. Answer the questions. For **Something is broken**, say what happened, what you expected and the steps that
   lead to it, one step per line.
7. Choose **How bad is it**.
8. Select **Review what is sent**. Read [Check what is sent](check-what-is-sent.md) for the next step.

## Things to note

- Nothing you have typed into the page's own fields is ever read, so it is safe to report a form you have
  filled in.
- One report per problem helps the team fix each one. Start again for the next problem.
