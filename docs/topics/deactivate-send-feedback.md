# Deactivate Send feedback

How-to

If you would rather not have the 'Send feedback' button, deactivate it. The choice is kept in this browser.

## Steps

1. Go to the site's settings. The setting is often with the display or accessibility settings.
2. Deactivate **Show Send feedback**. The button goes at once.
3. To bring it back, activate **Show Send feedback**.

## Things to note

- The setting's name and place are up to each site. If you cannot find it, ask the site's team.
- The choice belongs to this browser. On another computer or browser, deactivate it there too.
