# Post a report on GitHub

When you select **Open in GitHub**, GitHub opens a new issue with the report filled in. You post it from your
own GitHub account.

## Before you begin

- You need a GitHub account. Making one is free at github.com (opens in a new tab).

## Steps

1. Select **Open in GitHub** in **What is sent**. A new tab opens on GitHub.
2. If GitHub asks, sign in.
3. Check the title and the report. You can still change them here.
4. Select GitHub's button to create the issue. It is posted and the team is told.

## Things to note

- The issue shows your GitHub user name, as everything you post on GitHub does. The report itself holds no
  personal information.
- If the report was too long for GitHub's web address, Snaglist puts it on your clipboard and says so. Paste
  it into the issue before you create it.
- Labels such as `ux-report` are only added when you are allowed to label issues in that project. The kind and
  how bad it is are written in the report as well, so nothing is lost.
