# Use an AI assistant to add Snaglist

If you build with an AI coding assistant, it can add Snaglist, set it up and take it out again for you.
Copy one prompt into the assistant, answer its questions, and check what it did.

## Before you begin

- Open your project in the assistant you use: a chat that can change your files, or an editor with an
  assistant built in.
- Know where reports should go: a GitHub repository (`owner/repo`) or an email address.

## Steps

The quickest way is the [set-up tool](use-the-set-up-tool.md): choose your settings and copy one prompt with
everything in it. To use the general prompt instead:

1. Open [the prompts for AI assistants](../AI-PROMPTS.md).
2. Copy the prompt **Add Snaglist to my app**, from the line after "Copy from here" to the line before
   "Copy to here".
3. Paste it into your assistant and send it. It asks you up to six questions, then makes the changes.
4. When it says it has finished, open your app and check that **Send feedback** appears.
5. Make a test report: [Report a problem with one thing on a page](send-feedback.md).

## Things to note

- The same page has prompts to turn Snaglist off, to record more during a test session, and to remove it.
- Any assistant can also read [llms.txt](../../llms.txt), a short summary of Snaglist written for AI tools.
- Check the assistant's changes before you publish them, as you would anyone's.
