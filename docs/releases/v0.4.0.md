# Snaglist v0.4.0

Released 8 November 2026.

## Added

- **Show as a QR code.** With GitHub set up, **What is sent** offers the same pre-filled new issue as a QR code,
  for a phone to open when the computer is not online, such as one being set up. It comes first when the
  computer looks offline, with the reason above the privacy statement. A long report goes in shorter: first
  without its technical details, then with the words cut to fit, and the view says what the code holds. The
  link is shown as text with **Copy the link**, and **Download** keeps the whole report. The code is dark on
  light in every theme, with a text description, and works from the keyboard. The encoder is part of
  `snaglist.js`, so there is still one file and no libraries. Leave it out with `send: { qr: false }`.
  [Send a report with a QR code](../topics/send-a-report-with-a-qr-code.md) has the steps.
- **The help centre on the web,** at https://themightytrex.github.io/snaglist/help/, with search, a menu of every
  article and display settings.
- **A changelog,** in `CHANGELOG.md`, listing every version since 0.1.0.

## Security

- **The QR code holds only what the preview shows.** Nothing typed into the page, and no email address or key,
  reaches the code (test SEC-20). The QR tests, QR-01 to QR-05, check the encoder against the design system's
  own and the view in every theme.

Size: about 128 KB, or about 40 KB compressed.
