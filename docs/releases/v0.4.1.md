# Snaglist v0.4.1

Released 17 November 2026.

## Changed

- **Works under a strict Content Security Policy.** Snaglist draws its styles with a constructed style sheet
  instead of a style element, so it works on pages whose policy is `default-src 'self'`, with no
  `'unsafe-inline'` for styles. Nothing changes in how it looks or what it sends.

Size: about 125 KB, or about 40 KB compressed.
