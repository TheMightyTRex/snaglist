# Snaglist v0.5.0

Released 17 November 2026.

## Changed

- **Report types renamed.** Hard to use is now **Confusing to use**. Looks wrong is now **Display problem**. Hard to use
  with my tools or needs is now **Does not work with my tools or needs**. Their ids change with them: `ux` is now `confusing` and `visual` is now `display`. Nothing breaks. The old ids still work in `types`, `data-types`,
  text keys such as `types.ux.label`, `Snaglist.open()`, links from the set-up tool and a recording that was running
  during the update.
- **Existing GitHub issues keep their old labels.** Issues filed before keep `type: ux`, `type: visual` and
  `kind: looks`. New issues get `type: confusing`, `type: display` and `kind: appearance`. To keep one label
  for each, rename the old labels in **Issues**, then **Labels**, on GitHub.
- **Kinds of issue renamed.** In the everyday UX list, Looks is now **Appearance**. In the WCAG list, the four
  are **Cannot read or hear it**, **Cannot operate it**, **Unclear** and **Does not work with my tools**. In
  Nielsen's list, error prevention is **Mistakes are likely**.
- **Clearer words.** Text on screen is now **Text on the page**. The button that posts to your own server is **Send report**. Download is **Download as JSON**. The offline notice says "This computer seems to be offline: scan the
  code with your phone instead." The help, the demo and the set-up tool use the same words.
- **Colours match the design system.** The fallback colours for the sunken surface, the danger text and the
  scroll bars match `tokens.css` in light and dark. Borders replace shadows outside dialogs, and the type
  sizes are the design system's.

## Fixed

- **Errors stay until they are closed.** When a report is not sent, or the accessibility check cannot run, the message
  shows in the dialog and is read out at once. It stays until you close it. It says what happened and what to do, with
  the raw error under **Technical details**.
- **Messages are read out the first time,** stay while the pointer or keyboard focus is on them, and show in
  the dialog they are about.

## Security

- No change to what a report holds or where it goes. New tests: MSG-01 and MSG-02 for messages, TYPE-01 for the
  old type ids, WORD-01 and WORD-02 for the wording rules, and TOKENS-01 for the colours.
