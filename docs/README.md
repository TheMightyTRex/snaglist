# Snaglist help centre

![Snaglist](images/logo-wordmark.svg)

Help for adding Snaglist to a site, running it, using it and removing it, and for the people who send feedback
with it. Start with a guide if you have a goal in mind, or use a topic for one task.

**Quickest start:** the [set-up tool](https://themightytrex.github.io/snaglist/configure.html) writes the code, says
where it goes, and gives one prompt for your AI assistant. Other prompts are in [Prompts for AI assistants](AI-PROMPTS.md).
