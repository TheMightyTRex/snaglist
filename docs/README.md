# Snaglist help centre

Help for adding Snaglist to a site, running it, using it and removing it, and for the people who report
issues with it. Start with a guide if you have a goal in mind, or use a topic for one task.

**Building with an AI assistant?** Copy a prompt from [Prompts for AI assistants](AI-PROMPTS.md).
